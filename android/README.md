# Projeto Android nativo

Este diretório contém o aplicativo Android em Kotlin + Jetpack Compose.

## Abrir no Android Studio

1. Abra o Android Studio.
2. Escolha **Open**.
3. Selecione a pasta `android/` deste repositório.
4. Aguarde a sincronização do Gradle.
5. Execute o módulo `app` em um emulador ou dispositivo.

## Recursos da primeira versão

- Biblioteca de músicas
- Criar, renomear e excluir músicas
- Editor de cifras
- Pré-visualização
- Transposição em semitons
- Persistência local com SharedPreferences
- Tema escuro inspirado no projeto web
